## What it does

- `#[derive(Document)]` reads the struct: `#[index(…)]` names its index, and `#[semantic_text]` maps `text` as a `semantic_text` field, which Elasticsearch embeds as documents are indexed.
- `client.index::<Passage>()` is an `Index<Passage>`, which reads, writes and searches that type. `refresh(Refresh::WaitFor)` makes each write wait until searches can see it.
- `ensure_mapping` creates the index with the type's mapping if it doesn't exist, adds the fields an existing one lacks, and reports fields mapped differently, which it never changes.
- `Passage::TEXT` is the field's handle. A `semantic_text` field offers `semantic`; a keyword field would offer `term` and `terms` instead.
- Each hit carries its score and its source, read back as a `Passage`.

<Aside title="When something fails">
	Every call returns `Result<_, oxsearch::Error>`. A request for a feature the cluster's license doesn't include fails with `Error::License`, which names the feature; Elasticsearch's own errors are `Error::Elasticsearch`, with the status and the error's type and reason.
</Aside>
